# Vimaroni - Sistema de Inventario

Sistema de inventario profesional para gestión de productos por zonas y contenedores.

## Características
- ✅ Gestión de más de 6,000 productos
- ✅ Organización por zonas y contenedores  
- ✅ Mapa visual del galpón
- ✅ Búsqueda avanzada
- ✅ Interfaz responsive

## Tecnologías
- Frontend: HTML5, CSS3, JavaScript
- Backend: Node.js + Express
- Base de datos: MongoDB
- Hosting: Compatible con hosting tradicional

## Instalación en hosting
1. Subir archivos al servidor
2. Configurar variables de entorno
3. Instalar dependencias: `npm install`
4. Iniciar: `npm start`
